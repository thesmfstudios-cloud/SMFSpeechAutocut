SMF SPEECH HIGHLIGHT ENGINE v1.2 - SINGLE SPEAKER TEST

TEST SCOPE:
One person's 20–30 minute event speech -> candidate cuts -> AI recommended 1–2 minute highlight.

1) Install FFmpeg and make sure `ffmpeg -version` works.
2) Install Node.js 18+.
3) Open server/.env from .env.example and set:
   OPENAI_API_KEY=sk-...
4) In server folder run:
   npm install
   npm start
5) Enable CEP debug mode in Windows Registry:
   HKEY_CURRENT_USER\Software\Adobe\CSXS.9
   PlayerDebugMode = 1
6) Copy this repo folder to:
   C:\Users\<YOUR_USER>\AppData\Roaming\Adobe\CEP\extensions\
7) Restart Premiere Pro 23.1.
8) Window > Extensions > SMF Speech Highlight Engine
9) Select ONE speaker's video clip in the timeline.
10) Choose 60 / 90 / 120 sec target.
11) Analyze Speech.
12) Review all AI candidate cuts and Preview any candidate.
13) Use AI Recommendation or manually check cuts.
14) Add Markers, or Build Premiere Sequence.

GPU NOTE:
No local Whisper or Ollama is used. Local machine only extracts audio with FFmpeg;
transcription and AI highlight analysis use the configured OpenAI API.
